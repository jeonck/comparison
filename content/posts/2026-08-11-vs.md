## Overview

적응형 학습 에이전트는 반복되는 복잡한 작업을 감지해 <strong class="kw">스킬화</strong>하고 SQLite FTS5 같은 지속형 메모리에 저장함으로써 사용할수록 점점 사용자에게 맞춰진다. 반면 무상태 에이전트는 매 요청마다 <strong class="kw">일회성 추론</strong>을 처음부터 반복하며, 이전 작업에서 얻은 경험을 다음 작업에 전혀 활용하지 못한다. 이 차이는 응답 속도, 비용, 개인화 수준에서 시간이 지날수록 점점 벌어진다.

| 개인화 수준 | 사용자별 작업 이력이 누적되며 점점 맞춤화됨 | 누적 이력이 없어 항상 동일한 일반적 응답 |
| 스킬 노후화 관리 | 환경 변화 시 저장된 스킬이 오래된 정보가 될 위험이 있어 무효화·버전 관리 필요 | 저장된 것이 없으므로 노후화 문제 자체가 발생하지 않음 |

## Key Differences

- 적응형 학습 에이전트는 반복 작업을 <strong class="kw">자동 스킬화</strong>하지만, 무상태 에이전트는 매번 동일한 추론을 반복한다.
- 지속형 메모리는 SQLite FTS5 같은 <strong class="kw">전문 검색 인덱스</strong>를 활용해 과거 경험을 빠르게 조회한다.
- 사용 기간이 길어질수록 적응형 에이전트는 <strong class="kw">토큰 비용</strong>이 줄지만, 무상태 에이전트는 비용이 일정하다.
- 저장된 스킬은 환경 변화에 따라 <strong class="kw">노후화</strong>될 수 있어 별도의 무효화 전략이 필요하다.
- 무상태 에이전트는 <strong class="kw">인프라 부담</strong>이 없어 구현과 배포가 단순하다.

## When to Use Each

**적응형 학습 에이전트**

- **반복적인 개인 워크플로우 자동화**: 동일한 사용자가 유사한 복잡한 작업을 여러 번 반복 요청하는 환경에서 스킬 재사용으로 속도와 정확도를 높일 수 있다.
- **장기 사용 비서형 에이전트**: 수 주에서 수개월에 걸쳐 사용되는 개인 비서형 에이전트는 축적된 메모리로 점점 더 맞춤화된 응답을 제공한다.
- **고비용 추론 작업 최적화**: 매번 처음부터 추론하면 비용이 큰 복잡한 작업일수록 스킬 캐싱으로 얻는 절감 효과가 크다.

**무상태 에이전트**

- **일회성 또는 다중 사용자 서비스**: 사용자마다 맥락이 전혀 다른 공개형 서비스에서는 개인화된 스킬 저장이 오히려 불필요하거나 오작동 위험이 된다.
- **민감 정보 보관 회피**: 작업 이력을 디스크에 남기지 않아야 하는 규제 환경이나 프라이버시 요구가 높은 상황에 적합하다.
- **단순하고 예측 가능한 배포**: 저장소 인덱싱이나 스킬 무효화 로직 없이 최소한의 인프라로 빠르게 배포하고 싶을 때 유리하다.
